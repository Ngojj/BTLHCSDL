# Assets used to render certificate PDFs

- `fonts/BeVietnamPro-*.ttf` — Be Vietnam Pro by Lâm Bảo, Vietnamese Foundry and contributors, licensed under the
  SIL Open Font License 1.1 (https://openfontlicense.org). Embedded so Vietnamese diacritics render correctly.
- `logoBK.png` — logo of Trường Đại học Bách Khoa, ĐHQG TP.HCM.

Files are read relative to the working directory (`assets/...`), so run the server from the `backend/` folder.
